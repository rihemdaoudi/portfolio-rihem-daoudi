# Portfolio - Rihem Daoudi

## 🚀 Démarrage

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans le navigateur.

## 📦 Build

```bash
npm run build
npm start
```



## 🛠 Technologies

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
